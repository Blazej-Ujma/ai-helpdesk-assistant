# AI Helpdesk Assistant

## Project Overview

This project is a simple AI-powered IT Helpdesk prototype.

The goal is to support an IT department by answering common IT questions and reducing repetitive support requests.

The application provides a simple web interface where users can ask IT-related questions.

If the chatbot cannot solve the problem, it can create a simulated support ticket.

This project is developed as a learning project for an IT apprenticeship application.
